# Paula Stephan sources

This directory is the recursive source trail behind Paula E. Stephan's work on science funding, scientific labor, prestige/priority, research organization, and the institutions that shape scientific work.

The root object is Stephan's 2012 book *How Economics Shapes Science*. The best publicly inspectable upstream bridge is her 2010 handbook chapter, “The Economics of Science,” which explicitly says that it draws extensively from her 1996 *Journal of Economic Literature* survey.

Documented chain:

**Stephan 1996 → Stephan 2010 → Stephan 2012**

The existing book note is at [`../books/paula-stephan-how-economics-shapes-science.md`](../books/paula-stephan-how-economics-shapes-science.md), and the thematic source map is at [`../sources/paula-stephan-public-source-map.md`](../sources/paula-stephan-public-source-map.md).

## What goes in this directory

For every source that Stephan relies on, the eventual treatment should contain:

1. the exact bibliographic citation;
2. where Stephan uses it, or the best provenance we can establish for why it belongs in her source trail;
3. a legal public-reading copy when one exists;
4. a local copy only when the work is public domain or its license clearly permits redistribution;
5. a substantive summary of what the source actually says;
6. its bibliography/references, transcribed as the next recursion frontier;
7. links to child source notes;
8. a rights/access label so “available on the Internet” is never confused with “licensed to mirror.”

## Recursion rule

For a source `S`:

- read `S` as far as access permits;
- record what `S` contributes to its parent claim;
- enumerate the bibliography of `S`;
- create or reuse one node for every cited source;
- recurse into sources that have not already been visited;
- stop a branch when a source has no references, all of its references have already been visited, or the bibliography cannot presently be verified.

The goal is therefore not an endlessly duplicated citation tree. It is a directed source graph with deduplication: the same Merton, Arrow, Nelson, Hagstrom, etc. node can have many incoming edges.

## Provenance labels

- **BOOK-CONFIRMED** — independently confirmed as used in Stephan's 2012 book.
- **PUBLIC-PRECURSOR** — directly cited in Stephan's public 2010 chapter.
- **1996-PRECURSOR** — directly tied to Stephan's 1996 survey when verifiable.
- **2012-COMPANION** — used in Stephan's 2012 *Nature* essay “Perverse Incentives.”
- **FOLLOWED** — the upstream source itself has been read far enough to summarize its contribution.
- **BIBLIOGRAPHY-CAPTURED** — its references have been transcribed into this graph.
- **QUEUE** — identified but not yet recursively processed.

## Rights labels

- **PUBLIC-DOMAIN / MIRROR-OK** — may be stored in this repository.
- **OPEN-LICENSE / MIRROR-OK** — license permits redistribution; record the license.
- **PUBLIC-READ / DO-NOT-MIRROR** — readable online but copyright or license does not permit us to republish it.
- **CONTROLLED-LENDING / DO-NOT-MIRROR** — Internet Archive/Open Library borrow or preview copy.
- **PAYWALLED / SUMMARY-ONLY** — use bibliographic metadata, lawful previews, reviews, abstracts, and independently available related papers.
- **RIGHTS-UNKNOWN / DO-NOT-MIRROR** — default to a link, never a local copy.

## Current root evidence

### Paula E. Stephan — *How Economics Shapes Science* (2012)

- Harvard University Press, 2012.
- Book reference section: pp. 307–348.
- JSTOR/De Gruyter provide records and institutional-access versions, but the book is copyrighted.
- Internet Archive/Open Library copies are restricted/controlled-lending copies, not redistribution permission.
- The 2012 bibliography has **not** been silently substituted with the 2010 bibliography.

### Paula E. Stephan — “The Economics of Science” (2010)

- In *Handbook of the Economics of Innovation*, vol. 1, pp. 217–273.
- Public-reading PDF: <https://users.metu.edu.tr/pamukcu/HandbookofInno2010.pdf>
- Copyright statement in the volume says Elsevier B.V., all rights reserved. Therefore: **PUBLIC-READ / DO-NOT-MIRROR**.
- Stephan explicitly says this chapter “draws extensively from Stephan (1996).”
- Its references occupy printed pp. 266–273 and are the first complete, verifiable recursion frontier stored here.

See [`Paula Stephan – The Economics of Science (2010) – bibliography.md`](./Paula%20Stephan%20%E2%80%93%20The%20Economics%20of%20Science%20%282010%29%20%E2%80%93%20bibliography.md).

## A useful substantive hypothesis to test rather than assume

Stephan's source trail gives us a way to test claims about universities and class without training the repository on a conclusion in advance. Her literature is unusually useful because it links several mechanisms that are often discussed separately: prestige and priority, cumulative advantage, scientific labor markets, graduate-student/postdoc labor, the allocation of grants and equipment, institutional risk shifting, and winner-take-all rewards. Recursive reading should preserve disagreements among the sources, including cases where later empirical work weakens an earlier theoretical claim.
