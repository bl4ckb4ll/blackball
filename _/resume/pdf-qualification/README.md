# Executed PDF comparison, not production acceptance

The input contract is [../pdf-qualification.md](../pdf-qualification.md).
The complete result and first blocking defects are in
[../reader-evaluation.md](../reader-evaluation.md).

Each reader directory retains stdout, stderr and exit status for the same
twelve committed synthetic PDFs. A reader exit status of zero is not a
qualification pass. The independent Idriç check programs reject both current
readers. `sources-and-fixtures.sha256` binds the actual source inputs and bytes;
`environment.tsv` binds the dependencies and observed executable hashes.

Reproduce with the exact source pins, official GHC/Cabal archive hashes and
the frozen package sets in `../pdf-readers/`. Build the libraries separately
with `cabal build all --disable-optimization --with-compiler=ABSOLUTE_GHC`
for hpdft and
`cabal build --project-file=cabal_no_viewer.project lib:pdf-toolbox-document --disable-optimization --with-compiler=ABSOLUTE_GHC`
for pdf-toolbox. Supply the observed host's GMP include/library directories
explicitly when needed. The task's library builds used four jobs for hpdft and
two for pdf-toolbox. These are foreign Haskell dependency builds, not an ICK
consumer build or an Idriç-to-C fallback.

Inside each respective Cabal project, compile the corresponding client through
`cabal exec --with-compiler=ABSOLUTE_GHC -- ghc -package hpdft -outputdir ABSOLUTE_BUILD -o ABSOLUTE_PROBE ABSOLUTE_HPDFT_PROBE_SOURCE`
or
`cabal exec --project-file=cabal_no_viewer.project --with-compiler=ABSOLUTE_GHC -- ghc -package pdf-toolbox-document -package pdf-toolbox-content -outputdir ABSOLUTE_BUILD -o ABSOLUTE_PROBE ABSOLUTE_TOOLBOX_PROBE_SOURCE`.
The [client source files](../../../examples/autogenerated/pdf-fixtures/foreign-readers/)
deliberately contain no résumé interpretation or OCR.

The canonical consumer invocation is
`grease ABSOLUTE_PROJECT/_/resume/pdf-compare.grease ABSOLUTE_HPDFT_PROBE ABSOLUTE_TOOLBOX_PROBE ABSOLUTE_PROJECT/_/resume/fixtures/pdf ABSOLUTE_NEW_OUTPUT`.
The four paths are caller-supplied absolute locations, independent of the
launch directory. The comparison script does not provision dependencies or
enable intake. It captures failing reader processes intentionally and records
their actual status; its own success means capture completed, not acceptance.

Compile `PdfFixtures.idric`, `PdfProbeChecks.idric` and `PdfSandboxProbe.idric`
through the named Idriç source pin using its Chez backend. Use separate build
directories and explicit output directories. For a source bootstrap, set its
observed `IDRIS2_PREFIX` and `IDRIS2_PATH` to the actual prelude/base/contrib
libraries; do not reuse another host's paths. The narrow local support-Makefile
adjustment excluded the inherited RefC build/install targets. No RefC compiler
was invoked to produce any test or intake artifact.

Run `pdf-probe-checks hpdft ABSOLUTE_NEW_OUTPUT/hpdft` and its `toolbox`
counterpart. **Both currently exit 1.** Keep those failures. A missing input or
output is not a pass. The supplementary Unicode mutation is BLOCKED for hpdft
because the unchanged baseline already fails, and PASS for pdf-toolbox.

`PdfFixtures.idric` deterministically writes ten well-formed fixture files.
The malformed negative case is the literal ASCII text `%PDF-1.4`, newline,
`truncated object and xref`, newline. Ghostscript generated the encrypted case
from `ordinary.pdf` with PDF 1.4, EncryptionR=3, KeyLength=128,
OwnerPassword=`synthetic-owner` and UserPassword=`synthetic-user`. These are
public synthetic fixture passwords, not credentials. Preserve the committed
encrypted bytes; regenerated encryption identifiers need not be byte-identical.

Poppler rendered ordinary, columns, the rotated/cropped page and mixed-page
fixtures for visual inspection. Its independent Unicode extraction and ordinary
word boxes are retained here. The Unicode PDF tests logical CMap values rather
than claiming that Helvetica visually contains all those glyphs. No private
document, extracted personal record, production deployment, hosted acceptance,
clean-host all-format run or OCR execution is included.
