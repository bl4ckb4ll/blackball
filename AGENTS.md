# Agent instructions

Apply the shared evidence and acceptance guardrails in
`isomorphisms/ai-ci/AGENTS.md`.

Before changing this repository, read its README and repository-local
documentation, inspect the current branch/worktree and nearby active work, and
preserve established architecture, terminology, source/build layout, and
explicit current human corrections.

Keep this file repository-specific. Add local rules as the project develops; do
not copy the shared `ai-ci` rulebook here.

## Occupational-outcome evidence

For placement, employment, salary, credential-to-job conversion, and other
occupational-outcome claims, apply
[`education/occupational-outcome-evidence.md`](education/occupational-outcome-evidence.md).
A school report is primary evidence of what the school reports, not independent
verification of individual jobs or a good bargain. Preserve original named
events, exact denominators, uncertainty and the source chain. Do not turn
secondary summaries or editorially selected people into employment rates.

For MFE questions, retrieve the [Berkeley/Paleologo case](education/cases/berkeley-mfe-paleologo.md)
and [GPT incident](llm/berkeley-mfe-placement-inference/README.md). Do not use
accepted offers, salary summaries, employer prestige or generic statements about
finance mathematics to establish purchased-course use or educational value.
Preserve contrary practitioner testimony and withdraw conclusions it invalidates.
