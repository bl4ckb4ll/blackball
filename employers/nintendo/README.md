# Nintendo opportunity map — first pass, 2026-09-30

This first pass focuses on Nintendo of America and the North American studios/technical groups visible through Nintendo's current careers site.

## Public structure

Nintendo states that Nintendo of America Inc., headquartered in Redmond, Washington, is a wholly owned subsidiary of Nintendo Co., Ltd. serving operations in the Americas.

The current Nintendo of America job board exposes explicit department labels including:

- Legal;
- Marketing;
- Corporate Services;
- Product Development;
- Business Development;
- Operations;
- Translation;
- Project Management;
- Finance/Accounting;
- Systems Engineering;
- Web Development;
- Business Analysis;
- Human Resources;
- Localization;
- Retail Sales.

Current roles also expose **Publisher Developer Relations** inside product-development/marketing work and **Supply Chain Operations** inside operations.

Source:
- https://careers.nintendo.com/studios/nintendo-of-america/

## Engineering and game-development organizations

The broader careers board currently distinguishes work attached to:

- Nintendo Software Technology (NST): game development;
- Nintendo Technology Development (NTD): software/platform engineering;
- Retro Studios: game development and support;
- Nintendo of America corporate/operations functions.

Current job fields include Game Development, Software Development - Games, Software Development, Systems Engineering and Web Development.

Source:
- https://careers.nintendo.com/jobs/

## Entry-gate evidence

The current board includes associate-level and contract roles in areas such as localization, configuration support, game design and software engineering. That is useful evidence of lower-seniority inventory, but it is not yet a measured graduate/apprenticeship pipeline.

## Next measurements

1. Separate NOA corporate, NTD, NST and Retro as distinct hiring markets.
2. Track associate/contract roles separately from experienced permanent roles.
3. Map Publisher Developer Relations, eShop, localization and supply-chain teams.
4. Search for recurring internships, university recruiting and technician/support routes.
5. Attach named managers only where the public posting establishes the reporting line.
