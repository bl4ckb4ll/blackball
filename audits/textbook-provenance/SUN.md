# Sun job · Where did this textbook claim come from?

Use extra-high reasoning in `bl4ckb4ll/blackball`. Start with `audits/textbook-provenance/PILOT.md` and the adjacent claim and source tables on branch `work/textbook-provenance-sun`. Produce a pilot a reader can use to answer “Who chose these categories?”, “What did the cited source actually measure?” and “Whose recollection is this?”

1. **Choose the pages before looking for claims.** Start with Glencoe geography and Weste and Harris on VLSI. Add a verified grades 6–8 student edition and a second edition of one title if accessible. Keep student text, workbook, teacher guide and publisher summary separately identified. Count pages available, pages yielding text and passages actually reviewed. Check scanned pages visually and record OCR failures. Aim for ten consecutive student pages per title. Retain passages that triggered no search rule.

2. **Record what the author commits to.** For a taxonomy, give the classification criterion, what the categories classify, whether they can overlap and whether the author claims to exhaust the possibilities. For a rule of thumb or measurement, keep the quantity, units, population and period. For a reported conversation, distinguish the speaker, the person recounting it and any independent record. Keep the remembered professor anecdote open until a book and page are identified.

3. **Test several ways to trace a passage.** Try phrase and pattern searches for numbered categories, consensus language and personal testimony. Follow footnotes, figure credits, bibliographies and errata. Rank paraphrases with sparse word vectors. Compare editions with overlapping word sequences to find changes such as a dropped qualification. If a dense embedding model runs, pin its revision and rank the same passages on the same queries. Record which method found each candidate and inspect the source before assigning a relationship.

4. **Make the judgments testable.** Keep separate fields for what the book cites, the earliest use located, and what the inspected source supports, qualifies or contradicts. Record the search boundary for unresolved claims. Hand-label held-out pages before running the methods. Report counts for correct flags, false alarms, missed claims and verified sources appearing in the first five results. Include a nearby citation belonging to a different claim, a repeated passage from the same source and a case where a reader supplies the missing page.

5. **Deliver one literate report and the next jobs.** Keep edition and page locators, source links, hashes, original annotations and readable Grease workflow scripts in Blackball. Apply its redistribution policy to source pages. Show each query, candidate page and judgment together. Generate static HTML and a Pythia-facing TSV of eligible annotations from the same reviewed records. Demonstrate that adding an accepted source updates both. Finish with **Decision and evidence**, **Recommended allocation**, **Earth follow-up job** and **Moon follow-up job(s)**. Give Earth the bounded implementation work and checks. Tie any Moon expansion to a specific passing Earth revision.
