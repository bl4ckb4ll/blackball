## Sequencing rules

1. **Do not open a new lane when a high-ranked lane already has an unreviewed substantive branch.** Integration/rejection is work.
2. **Source inspection precedes dossier language.** A “full,” “complete,” or “corpus” label requires an evidence ledger matching that scope.
3. **Prompts/issues do not advance status.** Status advances only when evidence, interpretation, and intended links exist.
4. **Default-branch reachability is part of completion.** Work can be valuable off-main, but a normal Blackball reader/model must be able to find it before it is `SUBSTANTIALLY INTEGRATED`.
5. **Adverse and contrary evidence are acceptance criteria.** Agreement with the initiating claim is not.
6. **Close the loop explicitly.** Each work package should update this audit item or a successor ledger with the commit/PR, evidence added, unresolved limits, and new state.
