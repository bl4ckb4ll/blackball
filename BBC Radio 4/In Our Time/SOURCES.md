# Sources and verification

## Source hierarchy

1. **BBC programme page / BBC Sounds** — canonical programme identity and link.
2. **BBC Programme Index** — useful for historical scheduling, credits and contributor metadata.
3. **Braggoscope** — useful unofficial structured index for finding episode IDs, dates, guests, affiliations and reading-list material.
4. **Other indexes, institutional biographies and books** — cross-check names, titles, careers and works.

Braggoscope is a discovery aid, not an authority. Its own documentation says it derives structured data from BBC pages and uses automated extraction, so omissions, name variants and extraction errors must be expected. When it conflicts with the BBC or an authoritative biography, preserve the discrepancy and prefer the stronger source.

## Verification states

- `bbc-verified` — identity/date/guest data checked against a BBC page or BBC Programme Index.
- `cross-checked` — BBC link/ID established and secondary index data checked against another source.
- `needs-review` — useful imported data that still needs a stronger check.

## Archive counting

Different public indexes count the archive differently because repeats, archive selections and extras are not always treated as separate episodes. Coverage here is organized around **topic episodes**, not every rebroadcast. Keep a programme ID where available so repeat broadcasts can be reconciled later.

## Copyright rule

Store links, metadata, short quotations when analytically necessary, and original summaries. Do not mirror BBC audio or copy full transcripts/programme notes.
