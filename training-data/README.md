# Training data moved

The phone LLM training collector and append-only training record store have moved to [`bl4ckb4ll/blackball-training-gym`](https://github.com/bl4ckb4ll/blackball-training-gym).

Do not add new records here. The canonical record path in the dedicated repository is:

```text
records/<trainer_username>/<year>/<month>/<record_id>.json
```

This directory remains only as a migration pointer; it contains no training records.
