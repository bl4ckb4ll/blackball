## Reproduction and limits

Run examples/autogenerated/bme-observation/check.fm through the recorded
Fieldmouse revision with the absolute repository directory as its sole argument.
Acquisition, commands and payload identities are recorded in execution.tsv.
The required runtime capabilities are supplied by the matching Fieldmouse source
revision recorded there. Once built, the checker needs no compiler, Node, network
or device operation.

Each artifacts.tsv uses repository-relative paths and SHA-256, excluding itself
to avoid a self-reference. The commit/delivery identity binds those manifests.
Receipts retain UNCOMMITTED as the truthful state when the checks ran; the
subsequent commit is identified by the repository handoff.
