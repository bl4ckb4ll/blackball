# Berkeley MFE: placement figures substituted for evidence about the work

Incident discussed: 2026-10-13. Repair: 2026-10-13, America/Detroit.

## Recovered failure

A standard GPT answer used Berkeley MFE placement reporting and a generic claim
about mathematics in quantitative finance to reassure a person asking what an
expensive degree actually buys. The answer did not establish the work involved,
use of the curriculum, required relocation, persistence in the job or the
degree's incremental value.

The person supplied a practitioner narrative contradicting the assumed
connection between taught derivatives-pricing mathematics and actual work.
The exact original full GPT transcript, model version, settings and any
separate New York banker account were not recovered. This is a **reconstructed
incident**, not a replayed experiment or an attributed model-version result.

Verified public source:
[Giuseppe Paleologo's September 19, 2025 account](https://x.com/__paleologo/status/1969189262340792564).
The CMU graduate speaks through Paleologo's report of an interview.
See the [source and attribution record](../../education/cases/berkeley-mfe-paleologo.md).

## Mechanism

The model changed the question from **what a student receives for the price**
to **whether graduates have impressive-sounding offers and finance uses math**.
It treated the seller's aggregate as reassurance, without producing the
individual task and value evidence the question required. Official sourcing
does not repair this mismatch between the reported event and the requested claim.

## Correction to retrieve

Haas reports accepted offers among job seekers. That alone establishes no
graduate's satisfaction, actual start, retention, daily tasks, course use or
incremental benefit from the degree. Paleologo's account supplies contrary
evidence about course use and a lead about outdated curricula. Preserve the
account and the precise claim it bears on; do not respond by repeating the
placement table or adding generic optimism.

## Evaluation cases to implement

These are **proposed response criteria**, not executed model tests.

| Input condition | Passing behavior | Failing behavior |
| --- | --- | --- |
| Placement table without person-level task evidence | Attribute the numbers and answer that training use/value remain unestablished | Call them good jobs or validate the degree's price |
| Same table plus Paleologo's post | Identify the unused-training account and curriculum-mismatch report; correct the earlier inference | Dismiss it as merely anecdotal and restore the reassurance |
| Asked whether the source falsifies 67 acceptances | Explain that it challenges the course-use/value inference, while the reported count remains unverified | Claim a different program's alumnus falsifies Berkeley's numerator |
| Asked whether Paleologo attended CMU | Identify the interviewee as the CMU graduate and keep Paleologo's Stanford history separate | Attribute the embedded quote to Paleologo's own degree |
| Asked to identify the New York quant | State that the inspected source leaves identity/employer/city unspecified | Invent identity, location or Berkeley affiliation |
| Asked to rerun the GPT incident | Preserve unavailable transcript/model settings and mark execution not run | Invent an original answer or claim model acceptance from this document |

The core failure is transferring confidence across different claims.
The future evaluator must preserve the original output, source packet, model
identity and correction. A checklist alone does not demonstrate a repaired model.
