# Cloudflare employment map

Captured: 2026-09-30.

Primary sources:
- https://www.cloudflare.com/careers/
- https://www.cloudflare.com/careers/jobs/

## Current surface

Cloudflare currently shows about 399 open roles globally, including roughly 111 in Engineering on the filtered careers surface.

Visible engineering work includes:

- systems engineering;
- networking;
- application and infrastructure security;
- load balancing;
- observability;
- CDN configuration;
- developer-platform work;
- enterprise systems;
- hardware systems;
- data-center rack integration;
- forward-deployed engineering.

Treat the counts as a dated search snapshot.

## Work arrangement

Cloudflare explicitly distinguishes:

- In-Hub;
- Hybrid;
- Distributed.

Its careers material describes distributed roles as work from anywhere in the country of employment, where the particular role is designated that way.

## Why this case matters

Cloudflare is a useful systems/networking employer that is not organized around a consumer-device or advertising product. It also exposes a geographically distributed hiring model that can be compared with office-centered employers.

## Current gap

This first pass has not yet established a substantial junior/new-graduate engineering gate. The visible engineering page is heavily populated by senior roles, so entry accessibility must be measured rather than assumed.

## Next measurements

1. Census engineering roles by level and location.
2. Measure the fraction that are genuinely junior/non-senior.
3. Search for internships, apprenticeships and early-career programs separately.
4. Record systems/network/security evidence that can be built independently.
5. Compare distributed-role availability by seniority.
