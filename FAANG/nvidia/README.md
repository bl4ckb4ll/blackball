# NVIDIA employment map

Captured: 2026-09-30.

Primary source:
- https://jobs.nvidia.com/careers

## Current surface

NVIDIA's job system currently exposes roughly 2,600 global postings and explicit filters for:

- Engineering;
- Research;
- IT;
- Operations;
- Facilities;
- Program Management;
- Professional Services;
- Sales and other business functions.

Its job-type filters explicitly distinguish:

- Intern;
- New College Graduate;
- Regular Employee;
- Management;
- Academic.

Current visible engineering demand includes systems software, GPU performance, firmware, data-center systems, hardware design, verification, mixed-signal, robotics and autonomous vehicles.

## Concrete entry evidence

A current **Software Engineer, Hardware Tools and Methodology - New College Grad 2026** posting is an explicit new-graduate gate.

The current job system also lists 2027 new-college-graduate categories for software engineering, GPU architecture, hardware ASIC engineering, robotics/autonomous vehicles, plus internships across developer/performance technology and hardware design.

## Why this case matters

NVIDIA spans unusually many engineering disciplines under one employer: software, low-level systems, electrical/computer engineering, silicon, verification, firmware, robotics, HPC and data-center systems.

It is therefore a strong test case for whether degree names correspond to actual occupational gates.
