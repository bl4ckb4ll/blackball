# Up series — index by participant

Each continuing participant has a folder with:

- a participant-wide longitudinal `README.md`;
- one Git symlink for every age/installment record from 7 through the pre-broadcast 70 file;
- an explicit participation-state line so a symlink is never mistaken for proof that the person gave a new interview in that installment.

The fourteen folders here correspond to the continuing longitudinal cohort, not every child briefly shown in the original 1964 programme.
